# Getting help with CodFlow

CodFlow is an open-source project. Here is where to go depending on what you
need:

## Bugs and feature requests

Open an issue in this repository. Please use the provided templates:

- **Bug reports** — `.github/ISSUE_TEMPLATE/bug_report.md`
- **Feature requests** — `.github/ISSUE_TEMPLATE/feature_request.md`

Before opening an issue, search existing issues to avoid duplicates.

## Security vulnerabilities

Do **not** open a public issue. Follow the instructions in
[`SECURITY.md`](./SECURITY.md).

## Documentation

The primary documentation is the repository [`README.md`](./README.md) and the
[`CONTRIBUTING.md`](./CONTRIBUTING.md) guide. A dedicated docs site is planned.

## Commercial / priority support

There is currently no commercial support tier. This project is maintained on a
best-effort basis.
