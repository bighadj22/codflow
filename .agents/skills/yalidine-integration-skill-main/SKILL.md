# Yalidine Integration

Use this skill when the work involves Yalidine parcel creation, fee estimation, wilaya/commune/stop-desk lookup, tracking, or webhook validation.

Start with the project README and the reference docs in this folder before writing code or creating API contracts. The goal is to align implementation with Yalidine's official behavior and avoid guessing about fields, signatures, or dashboard-only steps.

This skill is intentionally scoped to the Yalidine/Guepex API. Keep the work focused on the official API contract, webhooks, and the integration boundaries the account owner must complete in the provider dashboard.
